# Задание 1: Карта IT-ландшафта и схема интеграции приложений

## Описание

Данное задание содержит диаграммы, описывающие текущий IT-ландшафт банка «Стандарт» и схему интеграции приложений, участвующих в процессе открытия депозита.

## Файлы

### 1. `it_landscape_map.drawio`
**Карта IT-ландшафта банка «Стандарт»**

Матрица, показывающая распределение систем банка по организационной структуре и бизнес-возможностям.

**Оси матрицы:**
- **По вертикали:** Организационная структура банка (подразделения)
  - Управление обслуживанием в сети отделений
  - Кол-центр
  - IT-отдел
  - Управление депозитными продуктами
  - Управление кредитными продуктами
  - Команда цифровой трансформации

- **По горизонтали:** Бизнес-возможности
  - Обслуживание клиентов
  - Продукты банка
  - Кредитование
  - Депозитные продукты
  - Цифровая трансформация

**Ключевые системы:**
- **АБС (Oracle)** — основная система банка, используется в большинстве бизнес-возможностей
- **Система кол-центра (PostgreSQL)** — для обработки обращений клиентов
- **Интернет-банк (MS SQL)** — онлайн-канал обслуживания
- **Сайт (React.js)** — маркетинговый канал
- **Excel-файлы** — для расчёта ставок по депозитам и кредитам

**Цветовая кодировка:**
- 🟡 Жёлтый — АБС (Oracle)
- 🔴 Красный — Система кол-центра (PostgreSQL)
- 🟣 Фиолетовый — Интернет-банк/Сайт
- 🟠 Оранжевый — Цифровая трансформация
- 🟢 Зелёный — Организационные подразделения

### 2. `application_integration.drawio`
**Схема интеграции приложений — процесс открытия депозита**

Диаграмма показывает текущий процесс открытия депозита с участием всех систем и действующих лиц.

**Действующие лица:**
- Клиент
- Сотрудник отделения
- Сотрудник бэк-офиса
- Сотрудник отдела кредитования

**Системы по слоям:**

**Фронт-офис:**
- Система кол-центра (Java/Spring Boot, PostgreSQL)
- Рабочее место в отделении (АБС клиент)

**Core-системы:**
- АБС (Delphi, Oracle) — основная система бухгалтерии

**Бэк-офис:**
- Рабочее место бэк-офиса (АБС клиент)

**Внешние системы:**
- СМС-шлюз телеком-оператора
- Партнёрский кол-центр (внешний)
- Excel-файл (расчёт ставок) — ежедневная отправка по email

**Онлайн-каналы:**
- Интернет-банк (ASP.NET MVC 4.5, MS SQL)
- Сайт (PHP, React.js)

**Интеграции:**
- Прямое подключение к БД АБС от интернет-банка
- Заявки из кол-центра передаются в АБС
- СМС-уведомления через СМС-шлюз
- Excel-файл со ставками отправляется ежедневно по email от отдела кредитования в бэк-офис

## Как использовать

1. Откройте файлы `.drawio` в [draw.io](https://app.diagrams.net/) или [diagrams.net](https://diagrams.net/)
2. Отредактируйте диаграммы при необходимости
3. Экспортируйте в нужный формат (PNG, SVG, PDF)

## Основные выводы

1. **АБС — центральная система** — все бизнес-процессы зависят от неё
2. **Прямое подключение к БД** — интернет-банк подключён напрямую к БД АБС, что создаёт риски безопасности и производительности
3. **Ручные процессы** — расчёт ставок в Excel, передача по email — неэффективно и подвержено ошибкам
4. **Слабая интеграция онлайн-каналов** — сайт и интернет-банк имеют ограниченный функционал
5. **Перегрузка АБС** — база данных уже перегружена, что ограничивает масштабирование

## Следующие шаги

Для цифровой трансформации необходимо:
1. Создать промежуточный слой (API Gateway) между онлайн-каналами и АБС
2. Автоматизировать расчёт ставок и хранить их в БД
3. Интегрировать онлайн-каналы для подачи заявок на депозиты
4. Обеспечить зашифрованный обмен данными между системами
